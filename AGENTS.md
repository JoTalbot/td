# Инструкции для агентов (AGENTS.md)

Этот файл — правила для любых AI-агентов и разработчиков, работающих с репозиторием.

## О проекте

**Neon Bastion TD** — 3D tower defense для Android в неоновой sci-fi стилистике.

- Движок: **Godot 4.2+** (бесплатный, open source), рендерер **Mobile**.
- Язык: **GDScript** (строгая типизация где возможно).
- Вся графика **процедурная**: меши, материалы с emission, GPU-частицы, glow. Бинарные ассеты в репозиторий не добавлять без крайней необходимости.

## Правила работы

1. **Все правки пушить сразу в `main`** после каждого логического изменения. Коммиты осмысленные, на английском, в формате `type: description` (feat/fix/refactor/docs/chore).
2. Перед пушем проверять, что проект открывается без ошибок парсинга:
   `godot --headless --path . --import` и `godot --headless --path . --quit-after 2`.
3. Не ломать мобильный ввод: игра рассчитана на touch (тап — строительство/выбор, drag — орбита камеры, pinch — зум). Мышь эмулирует touch только для отладки.
4. Держать производительность мобильной: рендерер `mobile`, без тяжёлых теней/SSR/SSAO, частицы умеренно.
5. Тексты интерфейса — на русском. Комментарии в коде — на русском.

## Архитектура

| Файл | Ответственность |
|---|---|
| `scenes/Main.tscn` | Единственная сцена; всё собирается кодом из `Main.gd` |
| `scripts/Main.gd` | Композиция: окружение, свет, менеджеры, обработка тапов, постройка/выбор башен |
| `scripts/Board.gd` | Сетка 12×9, путь врагов (`PATH_CELLS`), процедурный ландшафт, порталы |
| `scripts/CameraRig.gd` | Орбитальная камера: drag-орбита, pinch-зум, колесо мыши |
| `scripts/GameState.gd` | Деньги, жизни, сигналы, game over |
| `scripts/TowerData.gd` | Константы башен: 4 типа × 3 уровня (cost, damage, range, fire_rate, slow, chain) |
| `scripts/Tower.gd` | Визуал башни, поиск цели (по прогрессу на пути), стрельба, апгрейд/продажа |
| `scripts/Projectile.gd` | Самонаводящийся снаряд, трейл, взрыв-частицы, крио-замедление, цепная молния теслы |
| `scripts/Enemy.gd` | Движение по пути, HP-бар (billboard), замедление, анимация смерти |
| `scripts/WaveManager.gd` | Бесконечные волны, 3 типа врагов, босс каждые 5 волн, масштабирование HP |
| `scripts/HUD.gd` | Весь UI кодом: верхняя панель, кнопки строительства, панель башни, game over |

## Геймплейные соглашения

- Экономика: старт 220 кредитов, 20 жизней; награда за волну `30 + wave*5`; продажа возвращает 60% вложений.
- Сложность: HP врагов ×`(1 + (wave-1)*0.22)`, число врагов `6 + wave*2`.
- Новые башни добавлять в `TowerData.DEFS` + ветку визуала в `Tower._build_visual()` + при необходимости эффект в `Projectile`.

## Сборка под Android

См. `docs/ANDROID_BUILD.md`. Кратко: установить export templates Godot 4.2.2, Android SDK, настроить keystore, `godot --headless --export-release Android build/NeonBastionTD.apk`.
