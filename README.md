# Neon Bastion TD

Неоновый sci-fi **3D tower defense** для Android на бесплатном движке **Godot 4**.

![Godot 4.2](https://img.shields.io/badge/Godot-4.2-478cbf) ![Android](https://img.shields.io/badge/Platform-Android-3ddc84) ![License MIT](https://img.shields.io/badge/License-MIT-yellow)

## Особенности

- 🌆 **Стиль — киберпанк**: ночной мегаполис вокруг арены — процедурные небоскрёбы с мерцающими окнами (шейдер), голографические вывески со скан-линиями и глитчем, неоновый дождь, летающий транспорт, пульсирующая неон-сетка на мокром асфальте, glow/bloom и пурпурный туман. Вся графика процедурная, без единого бинарного ассета.
- 🗼 **4 типа башен × 3 уровня прокачки**:
  - **Импульс** — быстрая универсальная турель;
  - **Рельсотрон** — дальнобойный снайпер с огромным уроном;
  - **Крио** — замораживает и замедляет врагов;
  - **Тесла** — цепная молния по нескольким целям.
- 👾 **3 типа врагов + боссы** каждые 5 волн, бесконечные волны с растущей сложностью.
- 📱 **Мобильное управление**: тап — строительство и выбор, drag одним пальцем — орбита камеры, pinch — зум.
- 💰 Экономика: апгрейды, продажа башен (60% возврата), награды за волны.

## Запуск

1. Установите [Godot 4.2+](https://godotengine.org/download) (бесплатно).
2. Откройте `project.godot` и нажмите ▶ — на ПК мышь эмулирует касания.

## Сборка под Android

**Автоматически (CI):** каждый пуш в `main` собирает APK через GitHub Actions — скачайте артефакт `NeonBastionTD-apk` со страницы Actions. Пуш тега `v*` публикует APK в GitHub Releases.

**Локально:** см. [docs/ANDROID_BUILD.md](docs/ANDROID_BUILD.md).

## Структура

```
project.godot        — настройки (рендерер mobile, landscape, touch)
scenes/Main.tscn     — главная (и единственная) сцена
scripts/             — вся логика на GDScript
docs/                — документация по сборке
AGENTS.md            — правила для AI-агентов и контрибьюторов
```
