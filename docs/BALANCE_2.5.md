# Balance 2.5

Цель: сохранить темп прогрессии без превращения мастерства трасс и войны территорий в обязательный гринд.

## Контрольные точки

- Бонус мастерства дороги: максимум 3 уровня.
- Бонус за связную сеть должен быть небольшим и ограниченным сверху.
- Смертельные трассы должны компенсировать риск наградой, но не становиться единственным эффективным маршрутом.
- Командир появляется только после устойчивого контроля дороги, чтобы не спамить элитными боями.
- Боссы 5/10/15 волн должны ощущаться как пики сложности, а не как гарантированный проигрыш.
- Караванные события должны увеличивать вариативность дохода, а не ломать базовую экономику.

## Сбор телеметрии для следующего прохода

Для каждого тестового рейса записывать: корпус, маршрут, опасность, число волн, достигнутую волну, лом, лут по ресурсам, урон фуре, число установленных/проданных орудий, победу/поражение, босса и причину поражения.

После минимум 20 рейсов пересчитать медианы и p25/p75 для награды и урона по каждому классу корпуса и маршрута. Балансировать только после этого, чтобы не оптимизировать игру по одному удачному забегу человека, который слишком любит нажимать на кнопки.
