# План Rust Road TD 2.5.0

Статус: стабилизация beta.

## Уже реализовано

- [x] Выбор косметики мастерства в Шоуруме.
- [x] Независимое включение табличек, костяных рогов, медной мачты и золотого знака.
- [x] Сохранение косметического набора и повторное применение после смены корпуса.
- [x] Командирские трофеи и рецепты Кузни «Костница» / «Проходчик».
- [x] Таймер недели и прогноз следующего хода войны.
- [x] Динамическая погода: ясный зной, пыльный фронт и пеплопад.
- [x] Фракционные раскраски корпуса: ржавчина, кость, медь и война.
- [x] Подвеска, отдача оружия и кинематографические пролёты камеры.
- [x] Адаптивные профили «Качественный» / «Экономный».
- [x] Погода с игровыми модификаторами и визуальные повреждения.
- [x] Фракционные раскраски корпуса и четыре темы UI.
- [x] Фоторежим с PNG-снимками и кинематографическая камера.
- [x] Встроенный FPS-монитор для Android-тестов.
- [x] Караванный Казначей — элитная добыча караванных трактов с механикой побега.
- [x] Контратаки проигравшей фракции и экран фронта с предупреждением.
- [x] Автоматические регрессионные проверки детерминированных правил кампании.

## Командиры фракций

- [x] Каркас командиров для дорог, удерживаемых несколько дней.
- [x] Уникальные командиры Костяного Вала и Медного Провала.
- [x] Появление на дорогах после достижения срока контроля.
- [x] Трофеи командиров и рецепты Кузни.

## Новые боссы

- [x] Костяной Жрец — костяная клетка, тотем, свита и отдельный трофей.
- [x] Медный Бурильщик — тяжёлый карьерный тягач с фронтальной дрелью и трофеем.
- [x] Караванный Казначей — везёт сейф по караванным трактам и пытается уйти с поля боя; балласт-паника, груз-джекпот и рецепт «Граб-кран».

## Расширение войны территорий

- [x] Сила контроля дороги через длительность удержания.
- [x] Контратаки проигравшей фракции (предупреждение на фронте, рейс-оборона, награда за отбой).
- [x] Награды за удержание связной сети дорог.
- [x] Отдельный экран фронта с гарнизонами, сроком контроля и командирами.

## Интерфейс и качество

- [x] 3D-предпросмотр косметики с drag, pinch и колесом мыши.
- [x] Цветовые схемы корпусов за фракционные финалы.
- [x] Регрессионный smoke-тест кампании для ключевых правил.
- [ ] Полный Android smoke-тест на физическом устройстве.
- [ ] Баланс экономики и новых боссов по телеметрии тестовых рейсов.
