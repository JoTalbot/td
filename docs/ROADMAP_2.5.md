# План Rust Road TD 2.5.0

Статус: разработка начата после стабильного релиза v2.4.1.

## Уже реализовано

- [x] Выбор косметики мастерства в Шоуруме.
- [x] Независимое включение табличек, костяных рогов, медной мачты и золотого знака.
- [x] Сохранение косметического набора и повторное применение после смены корпуса.

## Командиры фракций

- [ ] По одному командиру для крупных территориальных блоков.
- [ ] Уникальная машина, силуэт, фаза и награда каждого командира.
- [ ] Появление на дорогах, которые фракция удерживает несколько игровых дней.
- [ ] Трофеи командиров и рецепты Кузни.

## Новые боссы

- [ ] Костяной Жрец — призывает лёгкие машины и ставит костяные заграждения.
- [ ] Медный Бурильщик — тяжёлый карьерный тягач с фронтальной дрелью.
- [ ] Караванный Казначей — защищает груз и пытается уйти с поля боя.

## Расширение войны территорий

- [ ] Сила гарнизона и длительность контроля дороги.
- [ ] Контратаки проигравшей фракции.
- [ ] Награды за удержание связной сети дорог.
- [ ] Отдельный экран фронта и недельная итоговая сводка.

## Интерфейс и качество

- [ ] Предпросмотр косметики без выхода из Шоурума.
- [ ] Цветовые схемы корпусов за фракционные финалы.
- [ ] Баланс и Android-тесты после каждого нового босса.
